## 🌾 Overview

**DairyPulse** is an innovative smart-farming solution for dairy farmers. Our main product is a **smart wearable neck belt for cows and buffaloes** that monitors animal health and activity, providing actionable alerts and insights through an intuitive digital dashboard.

Built using pure **HTML5, CSS3, and JavaScript**, this website delivers a modern, trustworthy agritech startup experience and a working e-commerce order workflow tailored for dairy farmers, farm owners, cooperatives, and agricultural evaluators.
